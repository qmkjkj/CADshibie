项目源码与识别结果提交说明
================================

2026-11-27 更新：下文保留早期提交说明和历史成绩。当前默认已加入原生边界残差细节头，历史同一1000页回归PQ为33.785%，清单总参数23,561,566，最近自动化测试记录152项通过；当前状态以README.md、validation.json和weights/manifest.json为准。本次只整理后续方案并提交Git，没有重新训练或评分。验证集、训练标签与结果目录保留本地，不随Git提交。详细下一步见docs/NEXT_OPTIMIZATION_PLAN.md。

一、运行环境
------------
- Python 3.13（本地测试 3.13.14），64 位 Linux/Windows 均可。
- 依赖安装：pip install -r requirements.txt
- 主要依赖：numpy、Pillow、scipy、scikit-image、scikit-learn、joblib、
  opencv-python-headless、torch。
- 全程离线，不访问外部模型 API。ViT 自动使用 CUDA（RTX 3060 上训练/推理），
  无 GPU 时自动回退 CPU，结果不变。

二、推理命令
------------
python infer.py --input <dev_final目录> --output results --engine hybrid --workers 8

或使用启动脚本：
./run.sh --input <dev_final目录> --output results --weights weights

默认引擎为 v2：精确描边色恢复 + 骨架折线几何 + 平行线优化 + ViT 语义
（与训练集颜色→类别先验融合）。关键参数：
  --confidence 0.35           ViT 置信度阈值
  --color-prior-weight 0.6    颜色先验融合权重（0 关闭）
  --class-policy weights/class_policy.json  逐类阈值/低精度类抑制
  --nms-iou 0.6               同类假设 mask-IoU 去重
  --max-instances 12          每图最多保留的 Thing 实例数（按置信度截断）
  --vit-device auto           ViT 设备（auto/cuda/cpu）
  --workers 4                 线程数（只影响速度）
旧引擎可通过 --engine v1 复现。详细参数见 README.md 第 3.3 节。

三、识别结果
------------
- results/ 下每张图一个 JSON，文件名与输入 PNG 去掉扩展名后完全一致。
- 每个 JSON 包含赛题要求的 12 个字段，写盘前由 cadvec/schema.py 校验。
- dev_final 共 1000 张，results/ 共 1000 个 JSON。

四、模型与数据来源
------------------
- weights/stroke_palette.json：train_final SVG 的 197 种精确描边色，
  用于抗锯齿 alpha 反混合后的颜色恢复，0 个神经网络参数。
- weights/color_class_prior.json：描边色→类别分布（train_final 统计），
  与 ViT 概率融合，0 神经网络参数。
- weights/vit_strokes.pt：小型 ViT 对象分类器，2,911,525 参数，4 通道
  224×224 输入（白底 RGB + 对象掩码），patch16/宽192/6层/6头；在 GPU 上
  用 bf16 训练 14 轮，验证集 macro-recall 42.65%。
- weights/yolo_seg.pt：YOLOv8n-seg 实例分割（3,399,033 参数），GT 实例
  凸包监督，为 hybrid 提供类别接管与 class 8 检测掩码门控。
- weights/gat_primitive.pt：图元级 GAT（356,373 参数），节点=14 维几何
  + 256 维图像特征，用于 class 8 实例并集。
- weights/resnet18_layer3.pt：torchvision ResNet18 conv1–layer3 主干
  （2,787,279 个张量元素），随包提供，离线环境不再触发权重下载。
- weights/roi_ink.pt：ROI 实例墨迹细化 U-Net（1,948,847 个张量元素），
  在 YOLO 检测框内预测实例墨迹并矢量化为 4 点折线；GPU 训练/推理，
  用于 class 2/8/14/18/22/28。
- weights/roi_ink_c2.pt：class 2 专用 192×192 ROI 墨迹 U-Net（1,948,847 个
  张量元素，30 轮，Dice 0.815），默认负责 class 2。
- weights/roi_ink_256.pt：256×256 ROI 墨迹 U-Net（1,948,847 个张量元素），
  13 类、1500/类、20 轮（Dice 0.801），负责 class 8/12/14/15/18/19/20/21/22/25/27/28。
- weights/roi_ink_unified.pt：统一类别条件 256×256 ROI 墨迹 U-Net
  （1,948,847 个张量元素，30 个 Thing 类、21,284 实例 + 4,926 难负例、24 轮，
  Dice 0.760），作为 512 模型的微调起点/消融保留。
- weights/roi_ink_512.pt：512×512 统一类别条件 ROI 墨迹 U-Net
  （1,948,847 个张量元素，从 256 微调 10 轮，Dice 0.696），默认接管
  class 3/4/26/29；几何往返显示 512 裁剪严格命中率 86.3%（256 为 74.0%）。
- weights/roi_quality.json：旧版学习式 ROI 实例质量门控（0 参数）。
- weights/roi_quality_all.json：256 模型版本的学习式质量门控（0 参数）。
- weights/roi_quality_512_all.json：默认质量门控（旧 13 类 + class 3/4/26/29，0 参数）。
- weights/stuff_unet.pt：全图 Stuff 语义 U-Net（1,929,971 个张量元素），
  30–34 五类、512 重叠分块；train_final 1,598 张含 Stuff 图纸训练，
  best val mIoU 0.333。
- weights/stuff_thresholds.json：Stuff 逐类概率阈值与最小面积（0 参数）。
- weights/roi_ink_all.pt：28 类 ROI 墨迹 U-Net（1,948,847 个张量元素），
  作为可选消融权重保留（默认关闭）。
- weights/roi_ink_quality.json：细化实例几何质量门限（0 参数）。
- weights/label_qa.json：GT 在 300/400/1000px 栅格下的稳定性诊断（0 参数）。
- 训练标签与评估口径对齐：Thing 且 instance-id=-1 的图元归入忽略类 35；
  对象假设按与 GT 实例的 IoU/覆盖率打标签。
- dev_final 推理只读取 PNG，不读取任何 SVG 或真值。
- 开源预训练声明：ResNet18（ImageNet1K，torchvision）作为 GAT 特征主干；
  YOLO A/B 实验使用 COCO/ImageNet 初始化的 yolov8n-seg 权重，仅用于对照，
  未进入默认提交权重；未使用任何私有数据集（赛题允许开源数据并声明）。
