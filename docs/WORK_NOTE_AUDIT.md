## 3. 企业新资料带来的规则变化

本节依据本次提供的本地资料，不代表另行核验了网站、网盘或排行榜。

### 提交范围

[问题列表](问题列表.md) Q1 规定企业赛包含三个任务：

| 任务 | 输出目录 | 当前说明中的文件数 | 评估信息 |
|---|---|---:|---|
| CAD | `results_cad/` | 809 | 当前项目使用 PQ；新 CAD 数据仍需和实际评分脚本核对。 |
| OCR | `results_ocr/` | 1000 | 文本位置与文本完全正确的端到端 F1。 |
| 表格 | `results_table/` | 135 | 公布脚本输出 AP、AP50、AP75、Precision、Recall、F1。 |

Q1 的总分公式为三任务得分各占 1/3。这里不是 CAD 内部的三个指标；本轮优化目标仍是 CAD PQ。当前仓库尚无 OCR、表格的完整预测入口。新资料没有明确 OCR 的哪个距离阈值、表格的哪个指标参与总分，暂不能做可靠的总分换算。

Q2 明确 dev 不提供标签，公布的评测脚本不变。因此收到纯 dev 图片时，可以检查输出、耗时、覆盖与视觉质量，但不能据此计算真实 PQ。原有本地 1000 张数据与新的 809 张 CAD 提交集也不能混用。

### OCR

[README_OCR](README_OCR.md) 的关键要求：

- JSON 包含 `image_width`、`image_height`、`svg_viewBox`、`annotations`；文字项包含 `text`、`x`、`y`。
- GT 提取保留 SVG 文本原生插入锚点，刻意不应用父级 transform；它不是普通 OCR 检测框中心。
- 预测支持 `svg_native` 或 `pixel` 坐标，评分会映射到像素距离；尺寸和 viewBox 必须与 GT 一致。后续需确认无 SVG 的输入如何取得对应元数据。
- 默认距离阈值为 5 / 10 / 20px，执行一对一匹配；端到端匹配还要求文本相等。代码做 NFC 与首尾去空格，大小写、内部空格、全半角、数字/小数位均无额外容错。
- 位置 F1 是辅助结果，不能代替要求文本正确的端到端 F1。

### 表格

[README_TABLE](README_TABLE.md) 的关键要求：

- 类别 ID 为 1 table、2 row、3 cell、4 header、5 column；不同类别区域允许包含、重叠。
- `bbox` 为原图像素 `[x, y, width, height]`，预测必须有 0–1 的 `score`。缩放后的框要恢复原图坐标。
- AP 对 IoU 0.50:0.05:0.95、存在 GT 的类别做平均，使用 101 点插值。默认 Precision/Recall/F1 使用 score≥0.5、IoU≥0.5，不能和 AP 混称。
- 空图按 Q3 使用 `annotations: []`，每图输出同名 JSON。
- 文档命令示例使用 `--gt/--pred/--out` 等参数，但内嵌脚本 `main()` 只接收两个位置参数并打印结果；实际运行应以发布的独立脚本为准。
- 文档仍有 dev 标签路径示例，但 Q2 明确 dev 无标签；不能据示例假定能取得 dev 真值。

Q5 允许公开预训练权重与公开数据，并要求记录来源和许可证；不允许私有数据。Q6 禁止外部 API 和本地部署的非本次任务训练的大模型。后续模型选择需按这些新资料判断。

## 4. 以 50% 为目标的实施顺序

当前记录的 precision≈44.6%、recall≈29.8%。如果 TP/FP/FN 固定，仅把已匹配实例的 IoU 提到 1，PQ 上限仍是 RQ≈35.7%。因此需要增加严格匹配的完整实例，尤其要把错位、几何污染或错误归属造成的 FP/FN 成对转成 TP。

1. **冻结并复现基线。** 保存代码版本、实际参数、权重/输入哈希、逐图预测与评分；单图失败必须显式记录。先用实际官方 CAD 评分器确认坐标、canonical 映射及汇总方式。
2. **联合审计数据重复。** 当前 [build_splits.py](../tools/build_splits.py) 分别对 train/test 做 dHash 分组，不能排除两者之间的重复页。联合检查精确像素、近重复和图纸家族，分别报告近训练页与未见家族的结果；模板库只使用训练部分的标注。
3. **固定候选，验证原生几何精修。** 在已有 YOLO 同类框内检索训练实例，完整保留图元、来源页和实例；先比较检测框、类别和分数不变时的几何收益。关键点充足时试局部 RootSIFT，关键点不足时走形状匹配；双向墨迹支持和多余线惩罚共同验收。
4. **诊断整页配准的覆盖与风险。** 小规模检查能可靠匹配多少页面、收益是否集中于重复图纸。仅在跨页面区域内点充分、残差小且局部原图验收通过时迁移；单独报告该分支在无整页匹配页面的表现。
5. **再增加补漏与竞争。** 在精修有效后引入多页候选、局部补漏、重复组撤销和实例竞争，记录新增 TP/FP、修好与修坏实例数。
6. **最后验证分割训练与多视图。** 比较独立 ROI 真实笔画监督与检测器冻结的分割微调，再加入清理图、裁片和尺度复核；每次只增加一个可归因环节。

当前 SIFT 实验的负结果只适用于已测试的候选来源和接入方式，不能据此跳过局部 RootSIFT 的受控验证；外部笔记的增量也不能相加作为本项目收益预期。

## 5. 防止过拟合的验收约定

- 有标签的数据按图纸家族分组；用 calibration 选择模型、阈值和类别路由，hold 确认泛化，final 在配置冻结后统一报告。反复根据某集合改方案后，该集合就不再是独立留出集。
- 模板库、检索索引、训练样本只来源于训练部分，保留来源记录；评估 SVG/JSON 只交给评测程序，正式推理仅读取允许的图像与元数据。
- 同时记录全量累计 PQ、逐类别 TP/FP/FN、几何失败原因、重复/未见页面分组及耗时；诊断膨胀分数与正式 `dilate=0` 分开报告。
- 每项改动保存独立预测和消融结果；只有跨组改善且退化可接受时才替换默认配置。50% 是目标，当前尚无数据支持保证达到。
