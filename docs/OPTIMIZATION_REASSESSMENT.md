# 优化路线重新评估：已做范围、论文证据和下一步选择

日期：2026-11-27。应用户要求，重新核对本地实现和实验，并检索论文、作者仓库及官方实现。本文是审计与方案选择，本次没有重训模型、下载权重或获得新 PQ。

**不能保证继续训练必然提高 PQ，也没有证据保证达到 50%。目前并未穷尽用户列出的优化方向。** 默认仍为第三轮历史 1000 页回归 PQ 33.785%；它不是无标签 809 页新 dev 的成绩。

## 1. 四个方向究竟做到了哪一步

## 2. 训练数据与失分证据会改变优先级

最新已观察的 155 页中，717 个 Thing FN 有 535 个存在框 IoU≥0.5 的同类框，31 个只存在达阈值的异类框，151 个没有达阈值的框。535 个里面，336 个所属类别已有原生 ROI 路由，但当前候选均无严格匹配潜力；这不是逐个确认 GT 实际经过了 native 网络。**检测和实例恢复都需要改，不能把全部漏分归因于检测器。** 框已过置信度/NMS，这不是完整的 pre-NMS 混淆分析。

当前原生训练构建器 `tools/build_native_detail.py:122` 会跳过部分多 GT 匹配接近或部分重叠的歧义检测框；每类检测候选上限为 4，GT supplement 仅取每类前 2 个。第四轮精确复用了这份旧裁片集合。它控制了变量，却没有为困难重叠归属重新设计样本。因此提示联合试验的负结果，不能替代专门的重叠归属训练。

只读统计当前固定 800 页完整 Thing 目标：class2 为 1451，class5/6/7 分别仅 4/2/1，class27 为 25。这说明该子集存在严重类别不平衡；它不是旧检测器完整 4000 页的类别频次统计。复制一个稀有实例很多次不会创造新来源或真实多样性。

旧 `tools/build_yolo_seg_dataset.py` 以实例凸包作为 mask 监督，会跳过不足 3 个凸包顶点的实例，并过滤没有有效多边形标签的页面；默认按文件名排序切出约 6% 验证页。新检测训练应重新检查细线实例、有效负页、来源组隔离和标签完整性。不能把凸包 mask 当作真实实例笔画监督。

默认检测权重 SHA 为 `1157d3014ad48fc376dee3fb9ce712f6df4a9798dcb7ea0c4d17e8cae395e1c5`，35 个输出类别的 YOLOv8n-seg、3,399,033 参数；这不证明每类都有充分监督样本。其保存的默认训练参数为 40 轮、640 输入、batch8、AdamW；历史初始化 A/B 文档的 batch16 不能套作该默认权重配置。第五轮只复用了编码器，未训练原 Segment 检测头。

## 3. 搜索到的可借鉴方法

下面“适用判断”均是结合本项目约束作出的推断，论文没有验证本项目的最终矢量 PQ。未以论文 AP/PQ 预测比赛涨分。

| 方法与主来源 | 论文/官方实现支持的机制 | 对本项目的适用判断 |
|---|---|---|
| [CondInst，ECCV2020](https://arxiv.org/abs/2003.05664)，[作者实现](https://github.com/aim-uofa/AdelaiDet) | 根据实例产生动态 mask 网络，区别于每个 ROI 使用同一固定网络 | 可作为“目标身份→笔画归属”的候选；仅加类别 embedding 或框坐标不等于复现 CondInst。它本身也不证明跨候选联合竞争已解决 |
| [QueryInst，ICCV2021](https://arxiv.org/abs/2105.01928)，[作者实现](https://github.com/hustvl/QueryInst) | 查询与实例/ROI 特征保持对应，动态 mask head 接受多阶段监督 | 对应联合实例建模；有预训练、阶段监督及训练配套，不能用本项目随机新头短试验代表其效果 |
| [Mask DINO，CVPR2023](https://arxiv.org/html/2206.02777v3)，[作者实现](https://github.com/IDEA-Research/MaskDINO) | 联合检测/分割、encoder 特征选择初始化 query、去噪训练、框与 mask 共同匹配 | 值得借鉴查询初始化和训练方式，适合解释第五轮缺少的训练机制；官方高资源配置不应直接照搬 |
| [SymPoint-V2，2024](https://arxiv.org/abs/2407.01928)，[作者实现](https://github.com/nicehuster/SymPointV2) | 图层特征与位置引导训练；额外中心 query 用于降低训练难度 | 位置引导比盲目延长自由 query 训练更值得比较；官方输入依赖矢量图元/图层，PNG 无法直接提供这些信息 |
| [RepeatFactorTrainingSampler，官方代码](https://detectron2.readthedocs.io/en/latest/_modules/detectron2/data/samplers/distributed_sampler.html) | 按含稀有类别的图像频次决定重复因子 | 可作为定向检测器重训的简单、可复现起点；应限制重复量并监测稀有类 FP 和微平均 PQ，不能只看尾类召回 |
| [SAHI，ICIP2022](https://arxiv.org/abs/2202.06934)，[作者实现](https://github.com/obss/sahi) | 切片辅助推理与微调，提升大图中的小目标处理能力 | 可作为检测召回对照，需要处理切边截断、重复和整体长构件；不自动改善已存在框内的实例几何 |
| [PointRend，CVPR2020](https://openaccess.thecvf.com/content_CVPR_2020/html/Kirillov_PointRend_Image_Segmentation_As_Rendering_CVPR_2020_paper.html) | 在自适应采样位置预测高分辨率分割 | 对细线监督/采样有借鉴价值；自然图像边界改善不能直接等价于本题的 1px 折线栅格改善 |
| [MP-Former，CVPR2023](https://openaccess.thecvf.com/content/CVPR2023/papers/Zhang_MP-Former_Mask-Piloted_Transformer_for_Image_Segmentation_CVPR_2023_paper.pdf)，[作者实现](https://github.com/IDEA-Research/MP-Former) | 训练中用扰动 GT mask 引导恢复，改善 masked-attention 的优化 | 可比较训练侧引导，推理必须只读 PNG；不能给模型提供推理真值或把该机制等同本项目已做的框 dx/dy |
| [VecFormer，NeurIPS2025](https://arxiv.org/abs/2505.23395) | 以线表示矢量图元，并融合实例与语义预测 | 有助于设计线/笔画 token，但输入图元本身是强条件；先从 PNG 恢复图元会引入新的几何误差，不能直接套公开分数 |

另检索到 [SCAHI，2026-11-16 修订预印本](https://arxiv.org/abs/2611.12657)，它在其测试数据上强调高分辨率单次推理与切片融合的公平比较。因此若做切片，应配同等分辨率/计算预算的整图对照；这只是外部研究提示，不是本 CAD 数据上的结果。

## 4. 结合本机资源选择，而不是只选择模型名

本机为 Windows、Python3.13、RTX4060 Laptop 8GB。[MaskDINO 官方安装](https://github.com/IDEA-Research/MaskDINO/blob/main/INSTALL.md)要求 Linux/Detectron2 并编译自定义 CUDA 算子；[官方训练说明](https://github.com/IDEA-Research/MaskDINO)的 R50 参考配置约需每卡 15GB，单卡需另设 batch 和学习率。SymPoint-V2 也有 pointops 等环境依赖。当前未验证这些模型在本机的可训练配置，因此不承诺直接完整复现。

可先复用现有 CAD 编码器、检测结果和原生几何能力，实施候选初始化的实例归属模型，并借鉴成熟训练机制。它仍属于新组合，需明确与官方复现区别。若采用公开 CAD 预训练权重，还要核对其训练来源与本地评估来源重叠；公开可用不等于没有标签暴露。

## 5. 建议的下一轮实验顺序（尚未实施）

**两条有明确分工的路线：定向检测器重训；检测候选初始化的联合实例归属。** 类别和目标提示作为归属模型的组成部分，不再把每次加一个 embedding 都包装成新的完整路线。

1. **先补齐训练样本。** 训练数据按来源组固定；统计完整训练侧类别频次，保留有效负页与细线实例，建立真正包含相邻同类、交叉背景线和重复候选的实例集合。旧构建器跳过的歧义样本需要可解释的一对一目标分配，不直接改成背景。困难样本只从训练折挖掘。
2. **检测器路线。** 对照同初始化、同更新预算的普通训练与类别平衡/难例训练。高分辨率和切片作为分开的对照，不把所有改变堆成一臂。记录每类框召回、错类与重复，最终固定原细节头检查整页矢量 PQ；mAP 改善不自动意味着采用。
3. **实例归属路线。** 固定检测器，使用其位置/特征初始化查询；联合读取同一冲突区域的多个候选，加入目标类别与位置条件，学习笔画属于哪个实例及背景。训练可借鉴位置引导/去噪；GT 存在共享笔画时保留共享关系，不盲目强制所有像素互斥。检查完整 mask 与导出几何，防止采样 Dice 好而整页掩码差。
4. **保留可归因对照。** 类别与目标提示至少做必要的拆分对照；两条主线先独立比较，均有证据后再检验组合。看到开发结果后不继续换阈值挑最好分。
5. **最后验收。** 先在固定开发范围检验，再对冻结候选做一次预定回归；报告总体 PQ、TP/FP/FN、主要退化与来源组不确定性。当前所有官方训练来源组已有实验暴露，来源分折只能增强稳健性分析，不能恢复“全新未见”身份。最终新 dev 没有标签，仍需真实评测确认。

这些实验尚未开始，不能保证哪一条一定提高分数。相较继续修改质量门限，它们更直接地针对当前已经确认的候选与实例恢复缺口。
