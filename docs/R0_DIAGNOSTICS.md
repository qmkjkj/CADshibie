> `python tools/diagnose_r0.py --pred-dir pred --gt-dir gt_json --raster 1000 --workers 16`

## 1. 汇总（Thing-only，raster 1000）

| 指标 | 数值 |
|---|---:|
| TP / FP / FN | 1642 / 3367 / 5246 |
| PQ / SQ / RQ | 18.912% / 68.514% / 27.604% |

与官方 micro（18.235%，含 Stuff）的差异来自 Stuff 的 441 个 FN 与 48 个 FP；
Thing 部分一致。

## 2. 原因标签

| 未匹配真值（FN）原因 | 数量 |
|---|---:|
| 无候选（没有任何重叠预测） | 3048 |
| 严重错位（有重叠但 IoU<0.3） | 1119 |
| 近阈值（0.3<IoU≤0.5） | 1036 |

| 碎裂 | 3 |

| 误检（FP）原因 | 数量 |
|---|---:|
| 与任何 GT 无重叠（文字/尺寸线/空白） | 1036 |
| 近阈值（0.3<IoU≤0.5） | 1116 |
| 多余笔画或错位 | 1159 |
| 错类 | 51 |
| 重复 | 5 |

结论：**79% 的 FN 是无候选或严重错位，错类仅 40**；主要矛盾是实例候选与
几何/矢量化，而不是语义分类。

## 4. 后续优先级

1. 无候选 FN：需要全图实例候选（提案 A1 的 query/class-agnostic proposal），
   而不是继续按类加检测头；
2. 严重错位 + 近阈值 FN（2155）：需要原分辨率 ROI 归属与更贴近评分器的
   矢量化/切段；
3. 近阈值 FP（1116）：与 FN 同源，几何修好后可同时转为 TP；
4. 文字/尺寸线等无 GT 重叠 FP（1036）：难负例已用于统一模型，但仍需
   局部语义/结构判别。
